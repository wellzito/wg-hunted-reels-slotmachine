# WG Hunted Reels - Slot Machine

Sistema completo de slot machine para Unity, desenvolvido para integração em jogos de cassino.

## Sobre o Projeto

WG Hunted Reels é um sistema modular de slot machine que inclui:
- Slot machine 3x5 com sistema de pagamento por padrões
- Sistema de bônus do polvo mecânico
- Mini-game interativo
- Sistema de replay com restauração completa de estado
- Animações com Spine (opcional)
- Tweens suaves com PrimeTween (opcional)
- Sistema de eventos totalmente desacoplado

## Funcionalidades

- Grid 3x5 com múltiplas linhas de pagamento
- 6 símbolos normais + 1 símbolo Wild
- Multiplicadores de 150x até 1x
- Sistema de bônus com multiplicadores acumulativos
- Mini-game do polvo mecânico
- Sistema de replay completo
- Auto-spin configurável
- Win sequence (Big Win, Mega Win, Super Win)
- Suporte a animações Spine
- Sistema de eventos desacoplado
